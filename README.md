# 指數墓城：骷髏討伐

[開始遊戲](https://stnhhs2003-creator.github.io/exponent-fps/)

單一 HTML 的第一人稱 3D 指數律答題遊戲。

- 圓形搖桿移動、拖曳瞄準、射擊；支援大屏觸控與 WASD。
- 三關獨立，每關 10 題、3 分鐘；答錯或單題逾時累計兩次失敗。
- 初階／進階／挑戰的單題時間為 25／20／15 秒。
- 骷髏巡走與逼近，最後兩題 Boss 加速。
- 連擊最高加分 60%；答對充能，100% 可冰封怪物 5 秒，倒數仍繼續。
- 1,856 道變式題，保存已出題紀錄，用盡後重洗。
- 假名排行榜依難度分類，資料只存目前瀏覽器。
- Web Audio 合成音效與氛圍配樂，角色參考使用者提供圖片。

原始網站部署工具：GitFolder Express，阿剛老師 https://kentxchang.blogspot.tw
