# 指數墓城：骷髏討伐

[開始遊戲](https://stnhhs2003-creator.github.io/exponent-fps/)

單一 HTML 第一人稱 3D 指數律答題遊戲。圓形搖桿移動、拖曳瞄準、射擊，支援大屏觸控與 WASD。

- 三關獨立，每關 10 題、3 分鐘；答錯或單題逾時累計兩次失敗。
- 初階／進階／挑戰單題 25／20／15 秒。
- 骷髏巡走與逼近，最後兩題 Boss 加速。
- 連擊最多加分 60%；能量滿可冰封怪物 5 秒，倒數仍繼續。
- 1,856 道變式題，保存已出題紀錄，用盡後重洗。
- 假名排行榜按難度分組，只存此瀏覽器。
- Web Audio 合成音效與氛圍配樂，角色參考使用者圖片。

## 武器與賞金

- 獵人手槍：均衡、充能 34%、射擊間隔 0.24 秒。
- 破骨霰彈槍：得分 ×1.25、充能 24%、射擊間隔 0.75 秒。
- 寒霜符文弩：得分 ×0.9、充能 50%、射擊間隔 0.55 秒。
- 每題前 8 秒答對追加 50×難度賞金；每連續 3 題答對再加 100×難度爆裂賞金。
- 衝鋒、Boss 狂暴與危險暗角不新增接觸扣命；仍由答錯或逾時扣命。
